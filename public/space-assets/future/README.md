# Original Space Market product illustrations

52 original, locally generated vector illustrations for the fictional Space Market catalog

- Authoring: custom SVG geometry and original Python standard-library generator
- External assets, photographs, stock art, fonts, brands, and paid generation services: none
- Output dimensions: 640 × 480, viewBox 0 0 640 480
- Palette: coordinated midnight showroom backgrounds, porcelain and graphite materials, cyan / lime / lavender accents
- Accessibility: each SVG includes a descriptive title and description
- Regeneration: run `python generate.py` from this directory
- Asset scope: illustrative fictional products only; no real product claims

The illustrations were created specifically for this project and may be modified and used with it
