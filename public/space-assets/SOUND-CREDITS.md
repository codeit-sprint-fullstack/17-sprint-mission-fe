# 우주마켓 발견·입장 효과음

사용자가 선택한 기존 음원에서 기내 알림음과 공기 방출음을 추가 가공 없이 나눠 재생합니다

| 파일 | 재생 시점 | 소리 | 길이 |
| --- | --- | --- | --- |
| `discovery-chime.wav` | NeoGround 푸터 5회 클릭으로 비밀 거래소를 발견할 때 | 기내 띵동 알림음만 | 2.23초 |
| `airlock-air.wav` | 우주마켓 입장 버튼을 누를 때 | 공기 방출음만 | 2.10초 |

- 44,100 Hz / 모노 / PCM16
- 사용자가 선택한 미리듣기와 동일한 PCM 샘플 및 음량으로 재생하며 파일 자체에서 이미 조용하게 조정했습니다
- 입장 공기음이 재생되는 동안 문을 닫아 두고 실제 재생 종료 이벤트에서 문을 열어 우주마켓을 표시합니다
- 직접 입장의 문 열림은 약 0.4초이며 모션 감소 설정에서는 즉시 표시합니다
- 음소거·재생 오류 시 입장은 계속되며 취소나 페이지 종료 후에는 늦은 소리 완료 이벤트가 입장을 실행하지 않습니다
- 발견 신호 도중 입장하면 신호를 멈추고 입장음으로 전환합니다
- 음소거 설정은 두 효과음에 공통 적용되며 취소하면 소리가 멈춥니다

## 원본과 기존 편집 이력

- 공기 방출음: [Air (or steam) pressure release — brunoboselli](https://freesound.org/people/brunoboselli/sounds/457294/)
  - 공기주입식 SUP 보드의 공기를 빼는 스튜디오 녹음
  - 공개 HQ 미리듣기의 앞부분 가공 테이크 2.1초를 사용해 음량과 가장자리 페이드만 조정
- 기내 알림음: [chime.wav — Shamrock132](https://freesound.org/people/Shamrock132/sounds/245851/)
  - Airbus A320 인터폰 알림음 녹음
  - 공개 HQ 미리듣기의 0.99~3.22초를 사용해 앞뒤 잡음과 수화기 클릭을 제외하고 음량과 가장자리 페이드 조정
- 두 원본 모두 [CC0](https://creativecommons.org/publicdomain/zero/1.0/)로 공개
- 기존 선택 음원 `airlock-entry.wav`의 0–2.10초 및 2.22–4.45초 PCM 샘플을 추가 가공 없이 분리했으며 두 소리 사이의 0.12초 무음은 제외
- 기존 합성 발견음과 합본 입장음 파일은 보관하며 현재 재생 경로에서는 사용하지 않음
- 사용자 참고 유튜브 영상의 음원은 포함되지 않음
- 목소리, 유료 서비스, 결제, 외부 업로드 없음
