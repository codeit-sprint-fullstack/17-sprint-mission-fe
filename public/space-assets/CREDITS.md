# 우주마켓 사진 출처

## 실사형 미래 상품 콘셉트

`photos/`의 JPEG 135장은 우주마켓의 가상 상품을 표현한 실사형 콘셉트 이미지입니다
실제 판매 제품이나 실재 인물을 촬영한 사진이 아니며 가정도우미는 성인형 창작 캐릭터입니다
사진처럼 보이는 재질과 조명으로 각 상품을 개별 제작했으며 생성 원본은 별도로 보존하고 사이트에는 JPEG 변환본을 사용합니다
상품 상세의 움직임은 코드로 만든 기능 시뮬레이션이며 실제 촬영 영상이나 작동 보증이 아닙니다
식품의 영양·보관 기간, 행성 부동산, 순간이동과 무중력 장치는 창작 설정입니다
기존 `future/` 벡터 파일은 이전 작업 기록이며 현재 상품 썸네일에서는 사용하지 않습니다

Starlink는 SpaceX가 설계·운영하는 위성 인터넷 브랜드이며 브랜드 관계는 [Starlink 공식 기술 안내](https://www.starlink.com/technology)를 참고했습니다
우주마켓의 Starlink 상품 구성·그림·가격은 학습용 가상 설정이며 SpaceX의 공식 상품·판매 제안·제휴가 아닙니다

## 사용 안내 확인

- [NASA Images and Media Usage Guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/): NASA 자료의 교육·정보·개인 웹페이지 사용에 대한 일반 허용 및 출처 표기·비후원 원칙을 확인했습니다. 선택한 NASA 자료의 카탈로그에는 별도의 제3자 저작권 표기가 없습니다.
- [JPL Image Use Policy](https://www.jpl.nasa.gov/jpl-image-use-policy/): RainCube 이미지에는 `Courtesy NASA/JPL-Caltech` 크레딧을 유지합니다. 후원이나 보증을 주장하지 않습니다.
- 이 기록은 현재 로컬 비상업적 학습용 사용에 맞춰 남겼습니다. 상업 판매나 상품 광고로 전환한다면 별도 사용 조건을 확인해야 합니다.

공식 라이브러리에서 조회한 개별 사진의 메타데이터와 다운로드 주소는 개발용 `asset-metadata.json`에 보관합니다. 사진 설명을 가상 상품 설명의 근거로 사용하지 않았습니다.
