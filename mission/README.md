# 🐼 판다마켓 스프린트 미션 1·2

HTML과 CSS를 활용하여 판다마켓 랜딩 페이지와 로그인·회원가입 페이지를 구현합니다.

## ✅ 요구사항 체크리스트

### 미션 1 — 랜딩 페이지

- [x] PC 시안에 맞게 페이지 디자인 구현
- [x] HTML과 CSS로 작성한 페이지를 Netlify에 배포
- [x] 로그인 버튼 클릭 시 `/login` 페이지로 이동
- [x] 구경하러 가기 버튼 클릭 시 `/items` 페이지로 이동
- [x] 스크롤해도 로고와 로그인 버튼이 있는 상단 내비게이션 바 고정
- [x] 클릭할 수 있는 요소에 `cursor: pointer` 적용
- [x] 화면 너비가 1920px일 때 로고의 왼쪽 여백과 로그인 버튼의 오른쪽 여백을 각각 200px로 설정
- [x] 화면 너비가 1920px보다 커지면 로고와 로그인 버튼 사이의 간격을 유지하며 가운데 정렬
- [x] 화면 너비가 1920px 이상일 때 하늘색 배경이 화면 너비를 가득 채우도록 설정
- [x] 화면 너비가 1920px 이상일 때 하늘색 영역 내부 요소의 위치를 고정하고 좌우 여백만 확장
- [x] 화면 너비가 1920px 이하일 때 내부 요소 간 간격을 유지하며 가운데 정렬
- [x] Privacy Policy 클릭 시 `/privacy` 페이지로 이동 (빈 페이지)
- [x] FAQ 클릭 시 `/faq` 페이지로 이동 (빈 페이지)
- [x] 페이스북·트위터·유튜브·인스타그램 아이콘 클릭 시 각각의 홈페이지를 새 창으로 열기
- [x] 화면 너비가 1920px일 때 `©codeit - 2024`의 왼쪽 여백과 SNS 아이콘 영역의 오른쪽 여백을 각각 200px로 설정
- [x] 화면 너비가 커져도 저작권 문구·Privacy Policy·FAQ·SNS 아이콘 사이의 간격을 유지하며 가운데 정렬

### 미션 1 — 심화 요구사항

- [ ] `reset.css` 설정
- [ ] 브라우저 글꼴 크기 설정에 따라 페이지 요소의 간격·크기·폰트 관련 값이 커지거나 작아지도록 구현

### 미션 2 — 로그인 및 회원가입

- [x] PC 시안에 맞게 로그인 페이지 디자인 구현
- [x] PC 시안에 맞게 회원가입 페이지 디자인 구현
- [x] HTML과 CSS로 작성한 페이지를 Netlify에 배포
- [x] 로그인·회원가입 페이지에서 판다마켓 로고 클릭 시 루트 페이지(`/`)로 이동
- [x] 로그인·회원가입 페이지의 로고 위 상단 여백을 동일하게 설정
- [x] 구글 아이콘 클릭 시 `https://www.google.com/`으로 이동
- [x] 카카오 아이콘 클릭 시 `https://www.kakaocorp.com/page/`로 이동
- [x] 입력창에 포커스가 있을 때 테두리 색상을 `#3692FF`로 설정
- [x] 입력창에서 포커스가 벗어나면 테두리 제거
- [x] 로그인 페이지의 회원가입 버튼 클릭 시 `/signup` 페이지로 이동
- [x] 회원가입 페이지의 로그인 버튼 클릭 시 `/login` 페이지로 이동

### 미션 2 — 심화 요구사항

- [x] 비밀번호 확인 입력창 오른쪽에 비밀번호를 확인할 수 있는 눈 모양 아이콘 추가
- [ ] 팔레트의 색상 값을 CSS 변수로 등록하여 사용
