# 판다마켓

중고 거래 서비스 **판다마켓**의 랜딩 페이지와 로그인·회원가입 페이지를 HTML, CSS로 구현한 프로젝트입니다.
코드잇 스프린트 미션 1, 2의 결과물입니다.

- 배포 주소: https://fs17-subin-pandamarket.netlify.app/

## 사용 기술

| 구분   | 내용                                                    |
| ------ | ------------------------------------------------------- |
| 마크업 | HTML5                                                   |
| 스타일 | CSS3 (reset.css, rem 단위)                              |
| 폰트   | [Pretendard](https://github.com/orioncactus/pretendard) |
| 배포   | Netlify                                                 |

## 페이지 구성

| 경로       | 설명                          |
| ---------- | ----------------------------- |
| `/`        | 랜딩 페이지                   |
| `/login`   | 로그인 페이지                 |
| `/signup`  | 회원가입 페이지               |
| `/items`   | 상품 페이지 (빈 페이지)       |
| `/privacy` | 개인정보 처리방침 (빈 페이지) |
| `/faq`     | 자주 묻는 질문 (빈 페이지)    |

## 주요 기능

### 랜딩 페이지

- 스크롤해도 상단에 고정되는 내비게이션 바
- 화면 너비가 1920px 이상이면 배경은 가득 채우고 내부 요소는 가운데 정렬
- 화면 너비가 1920px 미만이면 좌우 여백 200px을 유지
- 푸터의 SNS 아이콘을 누르면 새 창으로 이동

### 로그인 · 회원가입 페이지

- 로고를 누르면 `/`로 이동, 두 페이지의 로고 위 여백은 동일
- 로그인 ↔ 회원가입 링크로 서로 이동
- 구글, 카카오 아이콘은 각각 지정된 주소로 이동
- input에 focus하면 파란색(`#3692FF`) 테두리, 벗어나면 테두리 없음
- 모든 입력이 유효하면 CSS만으로 버튼 색이 파란색으로 변경
  - 이메일: 이메일 형식
  - 비밀번호: 8자 이상
  - 닉네임: 비어 있지 않을 것

## 폴더 구조

```text
.
├── index.html          # 랜딩 페이지
├── login/              # 로그인
├── signup/             # 회원가입
├── items/              # 상품 (빈 페이지)
├── privacy/            # 개인정보 처리방침 (빈 페이지)
├── faq/                # FAQ (빈 페이지)
├── css/
│   ├── reset.css       # 브라우저 기본 스타일 초기화
│   ├── common.css      # 공통 스타일
│   ├── header.css      # 랜딩 페이지 헤더
│   ├── landing.css     # 랜딩 페이지 본문
│   ├── footer.css      # 랜딩 페이지 푸터
│   └── auth.css        # 로그인, 회원가입 공통
└── images/
    ├── icons/          # SNS, 비밀번호 보기 아이콘
    ├── landing/        # 랜딩 페이지 이미지
    └── logo/           # 로고
```

## 실행 방법

빌드 과정이 없는 정적 사이트입니다. 링크가 `/`로 시작하는 절대 경로라서, `index.html`을 파일로 직접 열면 안 되고 로컬 서버로 실행해야 합니다.

```bash
# 프로젝트 폴더에서
npx http-server .
```

VS Code의 Live Server 확장으로 열어도 됩니다.

## 구현하면서 신경 쓴 점

- 모든 크기와 간격을 `rem`으로 지정해 브라우저 기본 글꼴 크기 설정에 따라 함께 변하도록 했습니다.
- 로그인과 회원가입 페이지가 `auth.css` 하나를 공유해 같은 스타일 규칙을 중복 없이 사용합니다.
- 버튼 색 변경은 `:has()`와 `:invalid` 선택자로 구현했습니다.
