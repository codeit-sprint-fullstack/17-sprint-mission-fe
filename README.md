# 판다마켓 스프린트 미션 2

HTML과 CSS를 사용해 판다마켓 로그인·회원가입 페이지를 구현했습니다.
이번 미션은 PC 화면 기준으로 기본 요구사항을 진행했습니다.

## 배포 주소
https://zingy-bienenstitch-0b954d.netlify.app/

## 페이지 주소
- 로그인: /login
- 회원가입: /signup

## 구현 내용
- 로그인 및 회원가입 페이지 구성
- 로고 클릭 시 메인 페이지로 이동
- 로그인·회원가입 페이지 간 이동 링크
- 구글·카카오 사이트로 이동하는 링크
- 입력창 선택 시 파란색 테두리 표시
- 이메일과 비밀번호 입력 시 로그인 버튼 색상 변경

## 사용 기술
- HTML
- CSS
- Git 및 GitHub
- Netlify

## Git 작업에 사용한 유닉스 명령어
- ls: 파일과 폴더 목록 확인
- cat README.md: README 내용 확인
