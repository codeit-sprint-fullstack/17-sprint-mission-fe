# 스프린트 미션 5 · 판다마켓

미션 1의 랜딩 페이지와 미션 4의 중고마켓을 이어서 구현했습니다. React가 화면을 표시하고 Express가 상품 조회와 등록을 처리합니다.

## 실행

Node.js 22.13 이상이 필요합니다. 프로젝트 폴더에서 다음 명령을 실행한 뒤 [판다마켓](http://127.0.0.1:3001)을 엽니다.

```powershell
npm ci
npm run build
npm start
```

코드를 수정하면서 확인할 때는 터미널 두 개에서 각각 `npm run server`와 `npm run dev`를 실행합니다. Vite가 표시한 주소를 열면 `/api` 요청이 Express로 전달됩니다.

## 구현한 경로

| 주소 | 동작 |
| --- | --- |
| `/` | 기존 랜딩 화면을 표시하고 구경하러 가기 버튼으로 중고마켓에 이동합니다. |
| `/items` | `GET /api/products`로 상품을 불러옵니다. 최신순 목록, 상품명 검색, 페이지 이동을 지원합니다. |
| `/registration` | 상품명, 소개, 판매가격, 태그를 입력하고 `POST /api/products`로 등록합니다. |
| `/items/:id` | 등록 성공 시 이동하는 빈 상품 상세 페이지입니다. |

상품 목록은 한 페이지에 PC 10개, 태블릿 6개, 모바일 4개를 표시합니다. 화면에서 공통 기본 이미지를 사용합니다.

태그는 입력한 뒤 Enter를 눌러 추가하고 × 버튼으로 삭제할 수 있습니다. 등록 데이터는 `data/products.sqlite`에 저장됩니다.
