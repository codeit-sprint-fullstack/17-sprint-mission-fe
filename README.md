# 🐼 판다마켓 (Panda Market)

코드잇 풀스택 부트캠프 17기 스프린트 미션 프론트엔드 프로젝트입니다.

## 📌 프로젝트 소개

판다마켓은 중고 물품을 거래할 수 있는 웹 서비스입니다.

HTML, CSS, JavaScript를 활용하여 Figma 디자인을 기반으로 웹 페이지를 구현하는 학습 프로젝트입니다.

## 🚀 스프린트 미션

### 스프린트 미션 1 — 랜딩 페이지

- 판다마켓 메인 페이지 구현
- HTML 시맨틱 태그를 활용한 페이지 구조 작성
- CSS를 활용한 레이아웃 및 스타일 구현
- 로그인 페이지 이동 링크 연결

### 스프린트 미션 2 — 로그인 및 회원가입

- 로그인 페이지 구현
- 회원가입 페이지 구현
- Figma 디자인 기반 UI 구현
- 이메일, 닉네임, 비밀번호 입력창 구현
- 비밀번호 표시/숨김 기능
- 구글·카카오 외부 링크 연결
- 입력창 Focus 스타일 적용
- CSS 색상 변수 활용

## 🛠 기술 스택

| 기술         | 사용 목적               |
| ------------ | ----------------------- |
| HTML5        | 웹 페이지 구조 작성     |
| CSS3         | 레이아웃 및 스타일 구현 |
| JavaScript   | 비밀번호 표시/숨김 기능 |
| Git / GitHub | 버전 관리               |
| Figma        | UI 디자인 참고          |

## 📁 프로젝트 주요 파일

| 파일          | 설명                        |
| ------------- | --------------------------- |
| `index.html`  | 판다마켓 랜딩 페이지        |
| `login.html`  | 로그인 페이지               |
| `signup.html` | 회원가입 페이지             |
| `style.css`   | 랜딩 페이지 스타일          |
| `auth.css`    | 로그인·회원가입 공통 스타일 |
| `reset.css`   | 브라우저 기본 스타일 초기화 |
| `img/`        | 이미지 및 아이콘 파일       |

## 💻 실행 방법

1. GitHub 저장소를 Clone합니다.
2. VS Code에서 프로젝트 폴더를 엽니다.
3. Live Server를 사용하여 `index.html`을 실행합니다.
4. 로그인 및 회원가입 페이지를 확인합니다.
